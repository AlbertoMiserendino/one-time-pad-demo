One-Time Pad Demo

A true one-time pad requires a uniformly random, secret key, as long as the message in bytes, used only once. This educational demo uses the browser's cryptographic random generator; it does not provide information-theoretic randomness, secure key exchange, or message authentication. Do not use it for sensitive data.

Try an encrypt-decrypt round trip

  1. Enter a message as plain text. Unicode characters may occupy several UTF-8 bytes.
  2. Leave the key blank and click Encrypt. The generated key appears above; keep it for decryption.
  3. Copy the ciphertext from In hexadecimal in Results, paste it into the Message field, and select hex as the message format.
  4. Keep the same key and its format, then click Decrypt. The decoded text should match your original message.
  5. For a new message, click Clear or Generate new key before encrypting. Never reuse a pad for another message.

Each output byte is message XOR key. Applying the same key again recovers the message because (M XOR K) XOR K = M.

For numeric input, separate bytes with spaces or commas: decimal 65 66, binary 01000001 01000010, or hex 41 42 all represent “AB”. Select the input format before entering bytes. All calculations run in your browser.
